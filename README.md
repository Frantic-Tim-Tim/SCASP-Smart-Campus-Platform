# SCASP — Smart Campus Academic Services Platform

## 1. Project Overview

The Smart Campus Academic Services Platform (SCASP) is a Java-based academic services management system designed to improve the delivery of academic and campus services within a university environment.

The platform aims to centralise academic services, simplify student interactions, improve communication and support efficient administrative operations.

## 2. Project Objectives

- Manage students, users and system roles.
- Provide a centralised course catalogue.
- Support course registration and waiting lists.
- Manage academic service requests.
- Publish campus announcements.
- Provide notifications and reporting.
- Maintain an audit trail of system activities.
- Provide access to campus services and locations.

## 3. Technology Stack

## 5. Project Structure

- `core-domain/` — Core entities and business rules.
- `concurrent-processing/` — Multithreading and concurrent operations.
- `network-gateway/` — TCP and UDP networking.
- `enterprise-services/` — Enterprise JavaBeans.
- `persistence-jdbc/` — Database access using JDBC.
- `web-application/` — Servlets and JSP.
- `rmi-administration/` — Remote administration services.
- `android-client/` — Android application.
- `database/` — Database scripts.
- `docs/` — Requirements, diagrams and project documentation.
