# Database

The schema targets MySQL 8.0+ and can be applied repeatedly:

```powershell
mysql --host=localhost --user=scasp_app --password scasp < database/schema.sql
mysql --host=localhost --user=scasp_app --password scasp < database/sample-data.sql
```

Create the `scasp` database and a least-privilege application account before
running these scripts. Do not put credentials in the repository. Sample records
are fictional and contain no passwords. The report queries in `reports.sql`
demonstrate course capacity, student registrations, service-request workload and
audited activity.

Application code receives a container-managed `javax.sql.DataSource`; production
connection pooling is configured by the Jakarta EE runtime, not by opening a new
physical database connection per user request.

Entity identifiers are generated by the application using random UUIDs and stored
as `CHAR(36)` values (or the matching domain string keys). Passwords are PBKDF2
hashes with per-account salts; the sample script deliberately leaves credential
columns `NULL` so demonstration accounts must be provisioned through
`JdbcAuthenticationService`.
